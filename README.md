# 脳内チェッカー / BRAIN CHECKER — Ver.1.0

**あなたの頭の中、バレてます。** 名前ひとつで、近未来の解析装置がしょうもない欲望を解析する、ASOBEATの娯楽用ブラウザゲームです。

公開URL：https://asobeatapps-ops.github.io/nou_checker/

## 遊ぶ・公開する

GitHub Pagesはリポジトリの **Settings → Pages → Deploy from a branch → main / (root)** を設定します。`index.html`、`style.css`、`js/`、`vendor/`、`assets/`、`.nojekyll` をそのまま配信します。公開後にNode.js・サーバーAPI・認証・鍵は必要ありません。

ローカル確認はHTTPサーバーで行います。ES Modulesを使うため、`file://`で直接開かないでください。

```sh
python3 -m http.server 8120
```

http://localhost:8120/ を開きます。

## 実装

- 名前入力→約5秒の解析→結果、称号図鑑、設定の5画面。解析スキップ、二重確定防止、バックグラウンド中断・明示的再開。
- オリジナルの左右半球・脳溝を持つThree.jsホログラム。ワイヤー・点群・走査線・HUDリング・結果の色分け、結果画面でのドラッグ回転。
- WebGL初期化失敗・コンテキストロスト・ライブラリ読込失敗では、点群のCanvasホログラムへ切り替え。診断と共有は続行できます。
- 20要素、5パターン、4レア度、30称号。割合は整数・合計100%。通常完了とスキップで同じ結果。
- 図鑑のNEW表示と重複防止、30種への到達時だけ専用コンプリート表示。再読込や同じ称号の再取得では再表示しません。
- 解析中だけの生成BGM、段階的な電子音、結果音とコンプリート音。OFF・スキップ・中断で不要な音を停止。
- 1080×1080、1080×1920の共有用PNGをCanvasで生成。画像プレビュー、保存、X投稿作成、対応端末のファイル共有、共有文コピー。
- 名前の共有は初期OFF。OFFなら共有画像・共有文章・ファイル名に名前を入れません。名前入り共有は明示的な選択後だけです。
- 広告配信なし。将来用コンテナは結果画面最下部に置き、初期状態ではDOMの`hidden`で非表示です。ダミー表示・空白は作りません。
- ASOBEATへの誘導は共通ヘッダー左上ロゴのみ。下部の別ゲーム誘導はありません。

## 固定診断の設計

アルゴリズムID：`brain-v1-fnv1a-avalanche-mulberry32`。

名前をNFKC正規化、前後空白除去、空白統一、小文字統一して検証します。UTF-8の固定FNV-1aハッシュとavalanche混合、Mulberry32 PRNGから、パターン・要素・割合・称号を一意に生成します。ひらがなとカタカナは別扱いです。表示名は計算用の正規化名と分けます。

診断コードは現在時刻、端末、日付、Math.randomを使用しません。演出に使う時間・角度は診断ロジックに渡しません。将来データや順序を変える場合は、このバージョンを維持するか新バージョンを明示してください。

パターンは指定された0.30 / 0.60 / 0.80 / 0.95の境界で選択します。整数の直接配分と生成可能な上限・下限を使い、再試行ループはありません。二極型は35%の生成枠で7組の特殊組み合わせを均等選択。通常生成から偶然特殊条件を満たすこともあります。バランス型には7要素と均等配分の生成枠があります。

10万件の詳細・全30称号の実際の取得用入力例は`reports/distribution.json`、検証内容は`QA_REPORT.md`を参照してください。テスト入力例はゲーム内には表示しません。

## 保存とプライバシー

`asobeat_brain_checker_v1`に保存するのは`schemaVersion`、取得済み称号ID、サウンド／演出軽減設定だけです。名前、診断履歴、日時、回数、端末IDは保存しません。名前を外部送信する診断APIや解析SDKもありません。X・端末共有はユーザーが選択した時だけ実行します。

保存拒否・破損時もメモリ上で遊べます。保存できない旨を表示します。図鑑初期化は確認後に実行し、設定値を維持します。現在の名前と結果はページ内メモリにのみあり、再診断で入力を空にします。

**本ゲームは娯楽用の診断です。科学的・医学的・心理学的根拠に基づく診断ではありません。**

## 演出軽減と資源

OSの`prefers-reduced-motion`と設定を両方尊重します。軽減時は揺れ・フラッシュ・自動回転・粒子の形成・走査線移動を抑え、点群も減らします。静止している軽減表示は再描画を省略します。結果の数値は直ちに確定値にします。

3Dは1つのRenderer／Canvasを画面間で移動し、同じBufferGeometryとカラーバッファを再使用します。DPRを1.7以下に制限し、重い場合は解像度・点数を下げます。描画ループは1本、非表示画面とバックグラウンドでは停止。画像URLは再生成・閉じる操作で破棄し、AudioNodeも停止・切断します。WebGL失敗時は不要な資源をdisposeします。

## 開発・検証

```sh
npm ci
npm test
npm run test:distribution
npx playwright install chromium webkit
npm run test:browser
node tests/audio-browser.cjs
node tests/visual-cases.cjs
```

`test:browser`には別ターミナルでのHTTPサーバーが必要です。`GAME_TEST_URL`でURL、`GAME_TEST_OUTPUT`で出力先、`CHROMIUM_PATH`で実行ファイルを変更できます。テスト既定値は`http://127.0.0.1:8120/`、Chromiumは`/usr/bin/chromium`です。WebKitとiPhone相当設定による確認は実機Safariと区別してください。

`tests/`、`reports/`、`DEVELOPMENT_SPEC.md`は開発・検証資料です。`node_modules/`と`test-results/`はGitに含めません。

## ファイル

- `index.html` / `style.css`：5画面・入力・図鑑・設定・共有シート・コンプリート演出
- `js/diagnosis.js` / `js/data.js`：固定診断、入力検証、20要素と30称号

- `js/main.js` / `js/effects.js`：画面状態・5秒の解析・確定・中断

- `js/collection.js` / `js/settings.js`：必要情報だけの保存と設定
- `js/share.js`：専用画像、X、端末共有、保存・コピー
- `vendor/`：固定Three.js 0.180.0とMITライセンス
- `assets/icons/favicon.svg` / `assets/images/ogp.png`：オリジナルアイコン・宣伝画像
- `LICENSES.md`：商用利用条件・素材の出典

## 未検証事項と今後の候補

実機iPhone／Androidの保存・共有シート、実際のスピーカー音質、OS支援技術、実機FPS・電池消費は未確認です。ブラウザが画像保存を実行しない場合も、プレビューの長押し保存を利用できます。WebGL投影で見える各色の面積は統計値そのものではなく、正確な値は数値とバーです。

今後は実機ごとの描画品質の調整、共有画像のデザイン追加、アクセシビリティの実機検証を検討できます。診断アルゴリズム、20要素・30称号、指定割合、名前を保存しない方針を変更する場合は、別の仕様変更として扱います。
