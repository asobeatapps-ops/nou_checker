# 脳内チェッカー / BRAIN CHECKER — Ver.1.1

名前ひとつで脳内の欲望を解析する、ASOBEATの娯楽用ブラウザゲームです。

公開URL：https://asobeatapps-ops.github.io/nou_checker/

## 現在の仕様

- 脳内要素21種類、エンディングも主成分ごとに1件ずつ、全21件。
- 割合は整数・合計100％。同率の場合は要素ID順で主成分を選びます。
- バランス30％、偏り30％、二極20％、極端15％、純粋5％。
- レアリティは通常、青RARE、紫EPIC、黄色LEGENDARY。レア度が上がるほど解析中の光輪・粒子・光線が増えます。
- 結果は既存の脳の輪郭内に100個の色付き文字を表示。1文字が1％に対応し、1％の要素も省略しません。
- 説明文は各140〜164字。図鑑・共有画像にも反映します。
- 名前入力→約5秒の解析→結果、称号図鑑、設定の5画面。解析スキップ、二重確定防止、中断・明示的再開に対応。
- タイトルと解析中はThree.jsホログラム。WebGL不使用時はCanvasへ切替。結果は回転しないCanvas 2Dです。
- BGMは解析中のみ。ミュート・演出軽減設定とOSの演出軽減に対応。
- 1080×1080／1080×1920のPNG保存、対応端末の画像共有、X投稿作成、共有文コピー。長い説明文は投稿用に要約し、画像には全文を載せます。XのWeb投稿リンクに画像を自動添付することはできないため、端末共有か保存後の添付を利用します。
- 名前の共有は初期OFF。広告は未配信で、結果下部の将来用広告枠は非表示です。

## 固定診断と保存

`brain-v2-fnv1a-avalanche-mulberry32`。NFKC正規化した名前を固定ハッシュとPRNGへ渡し、時刻や端末に依存せず構成を決めます。今回の21エンド化では構成比の抽選を変更していません。

保存キーは`asobeat_brain_checker_v1`、スキーマは2。保存するのは取得称号、称号の最高レアリティ、音と演出の設定です。名前・割合・履歴は保存しません。

旧図鑑からは称号1〜20と設定を維持し、旧31のH称号を新21へ移行します。今回廃止した旧特殊エンド21〜30は新図鑑に含めません。旧CRITICALはEPICへ移行します。

## GitHub Pages公開

Settings → Pages → Deploy from a branch → main / (root)。ビルド不要です。`index.html`、`style.css`、`js/`、`vendor/`、`assets/`、`.nojekyll`をそのまま配信できます。

## ファイルと検証

- `js/data.js`：21項目・21称号・説明文・確率・色
- `js/diagnosis.js`：固定診断と主成分のエンド選択
- `js/brain2d.js`／`js/brain3d.js`：結果の2D表示／解析ホログラム
- `js/effects.js`／`js/audio.js`：解析の進行・演出段階・音
- `js/collection.js`／`js/settings.js`：保存・移行・設定
- `js/share.js`：共有PNGと共有処理
- `tests/`／`reports/`：試験コード・10万件の分布・取得例CSV

`npm test`、`npm run check`、`npm run test:distribution`で検証します。今回の単体テストは39件成功。10万件で全21要素・全21エンドへの到達を確認しました。

今回追加した演出の実ブラウザ・実機での見た目／速度／共有操作は未検証です。詳細な実施範囲と過去の履歴は`QA_REPORT.md`を参照してください。
